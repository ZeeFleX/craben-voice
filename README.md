# CrabenVoice 🦀

Максимально простой голосовой чат для друзей. Открыл страницу — и ты уже в разговоре. Без регистрации, без комнат, без видео.

## Запуск

```bash
npm install
npm start
```

Сервер поднимется на `http://localhost:3737` (порт можно сменить: `PORT=8080 npm start`).

## Как пользоваться

1. Запусти сервер.
2. Дай друзьям ссылку на эту страницу.
3. При первом входе спросит имя («Здравствуй, краб, как тебя зовут?») — запомнит в localStorage, больше спрашивать не будет.
4. Браузер один раз спросит доступ к микрофону — разреши.
5. Говорите. Кнопка на странице включает/выключает микрофон — замьюченные видны всем (🔇 в списке).
6. На странице виден список всех в комнате; ползунком рядом с участником можно убавить/прибавить его громкость у себя (до 200% — для тихих микрофонов). У говорящего рамка подсвечивается.
7. В настройках на странице: выбор микрофона, шумоподавление RNNoise (давит клавиатуру и вентилятор лучше браузерного) и режим push-to-talk (говоришь, пока зажат пробел). Настройки сохраняются в localStorage.

## Как открыть доступ друзьям из интернета

Браузеры отдают микрофон только по HTTPS (localhost — исключение), поэтому нужен либо туннель, либо свой сервер с сертификатом:

- **Проще всего — туннель** (сервер запущен у тебя на компе):
  ```bash
  cloudflared tunnel --url http://localhost:3737
  ```
  Выдаст публичную `https://`-ссылку — кидай её друзьям. То же умеют `ngrok` и `localtunnel`.
- **Свой VPS:** подними там `npm start` и повесь перед ним Caddy/Nginx с бесплатным сертификатом (Caddy делает это сам по домену).

## TURN-сервер (coturn)

Без TURN часть участников с жёстким NAT (симметричный, некоторые мобильные сети) может не соединиться. TURN нужен на машине с публичным IP (VPS).

1. Поставь coturn: `apt install coturn` (или `docker run coturn/coturn`).
2. Минимальный `turnserver.conf`:

   ```conf
   listening-port=3478
   realm=crabenvoice
   use-auth-secret
   static-auth-secret=ПРИДУМАЙ_ДЛИННЫЙ_СЛУЧАЙНЫЙ_СЕКРЕТ
   ```

3. Открой на файрволе: `3478` UDP/TCP и диапазон ретрансляции `49152-65535` UDP.
4. В папке проекта создай `.env` (шаблон — `.env.example`):

   ```bash
   TURN_URL=turn:IP_ИЛИ_ДОМЕН_ТВОЕГО_VPS:3478
   TURN_SECRET=ТОТ_ЖЕ_СЕКРЕТ_ИЗ_turnserver.conf
   ```

5. `npm start` — сервер начнёт выдавать браузерам временные TURN-креды на сутки через `/ice-config`. Сам секрет в браузер не попадает.

Вместо секрета можно использовать постоянные логин/пароль (`user=логин:пароль` в turnserver.conf и `TURN_USER`/`TURN_PASS` в `.env`), но они будут видны всем, кто откроет страницу.

## Как это устроено внутри

- `server.js` — отдаёт статику, пересылает сигнальные сообщения между браузерами (Socket.IO) и выдаёт ICE-конфиг (STUN/TURN) на `/ice-config`. Звук через сервер **не идёт**.
- `public/client.js` — WebRTC mesh: каждый браузер соединяется с каждым напрямую (P2P), звук ходит напрямую между участниками (или через TURN-ретранслятор, если P2P не пробился).
- Звук перед отправкой обрабатывается через Web Audio: high-pass 90 Гц (срез гула), компрессор и шумоподавление RNNoise (`public/js/rnnoise-worklet.js` + завендоренный wasm из `@jitsi/rnnoise-wasm` в `public/vendor/`, ~2 МБ, грузится лениво при включённом шумодаве). Голоса собеседников играют через GainNode — поэтому громкость крутится выше 100%.
- STUN по умолчанию — публичный от Google; TURN подключается через `.env`, см. выше.

Комфортный предел mesh-схемы — примерно 5–8 человек в разговоре.

## Продакшн

Развёрнуто на VPS `91.218.247.62`, работает на `https://crabenvoice.kardapolov.pro`:

- Код: `/opt/crabenvoice`, юнит `systemd` — `crabenvoice.service` (автозапуск + авторестарт, логи: `journalctl -u crabenvoice -f`).
- TURN: `coturn` (`/etc/turnserver.conf`), секрет лежит в `/opt/crabenvoice/.env` (systemd подхватывает его через `EnvironmentFile`).
- nginx: `/etc/nginx/sites-available/crabenvoice.kardapolov.pro.conf` — прокси на `127.0.0.1:3737` с поддержкой WebSocket; SSL-сертификат выпущен certbot'ом, продлевается автоматически.

Обновление кода на сервере:

```bash
rsync -az --exclude node_modules --exclude .git --exclude .env ./ root@91.218.247.62:/opt/crabenvoice/
ssh root@91.218.247.62 'cd /opt/crabenvoice && npm install --omit=dev && systemctl restart crabenvoice'
```
